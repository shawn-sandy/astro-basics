## 1. Authentication & Authorization

### Authentication Security

- [ ] **Authentication Provider Security**

  - [ ] Clerk integration properly configured
  - [ ] API keys stored securely in environment variables
  - [ ] No hardcoded credentials in codebase
  - [ ] Webhook signatures validated (if using webhooks)

- [ ] **Session Management**

  - [ ] Session tokens properly validated
  - [ ] Session expiration configured appropriately
  - [ ] Secure session storage (httpOnly, secure cookies)
  - [ ] Session fixation protection

- [ ] **Password Security** (if applicable)
  - [ ] Strong password requirements enforced
  - [ ] Password hashing using bcrypt/argon2
  - [ ] Password reset tokens expire appropriately
  - [ ] No passwords in logs or error messages

### Authorization Security

- [ ] **Access Control**

  - [ ] Protected routes properly secured
  - [ ] Role-based access control (RBAC) implemented
  - [ ] Principle of least privilege applied
  - [ ] Authorization checks on all sensitive operations

- [ ] **API Authorization**
  - [ ] All API endpoints require authentication
  - [ ] API rate limiting implemented
  - [ ] API keys/tokens validated on each request
  - [ ] Proper scope validation for API operations

  - [ ] Content-Type validation

  - [ ] Parameter type checking

- [ ] **File Upload Security**
  - [ ] File type validation
  - [ ] File size restrictions
  - [ ] Virus/malware scanning
  - [ ] Secure file storage location

## 3. Cross-Site Scripting (XSS) Prevention

### Output Encoding

- [ ] **HTML Context**

  - [ ] User input HTML-encoded before display
  - [ ] Template auto-escaping enabled
  - [ ] No direct HTML injection
  - [ ] Safe HTML rendering libraries used

- [ ] **JavaScript Context**
  - [ ] JSON data properly encoded
  - [ ] No eval() or Function() with user input
  - [ ] No innerHTML with user content
  - [ ] Event handlers sanitized

### Content Security Policy

- [ ] **CSP Headers**
  - [ ] CSP header configured
  - [ ] Appropriate directives set
  - [ ] Inline scripts minimized
  - [ ] Report-URI configured

## 4. Cross-Site Request Forgery (CSRF) Protection

### CSRF Tokens

- [ ] **Token Implementation**
  - [ ] CSRF tokens generated for forms
  - [ ] Tokens validated on submission
  - [ ] Tokens unique per session
  - [ ] Double-submit cookie pattern (if applicable)

### SameSite Cookies

- [ ] **Cookie Configuration**
  - [ ] SameSite attribute set appropriately
  - [ ] Secure flag enabled for HTTPS
  - [ ] HttpOnly flag for session cookies

## 5. SQL Injection Prevention

### Database Queries

- [ ] **Query Security**
  - [ ] Parameterized queries used
  - [ ] Stored procedures where appropriate
  - [ ] No string concatenation in queries
  - [ ] ORM/query builder properly configured

### Database Security

- [ ] **Access Control**
  - [ ] Database user permissions restricted
  - [ ] Row-Level Security (RLS) configured (Supabase)
  - [ ] Connection encryption enabled
  - [ ] Database credentials secured

- [ ] **Additional Headers**
