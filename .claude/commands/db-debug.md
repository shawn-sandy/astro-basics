Advanced database debugging with verbose logging, connection diagnostics, and detailed error analysis.

This command provides comprehensive debugging tools:

- Verbose logging with detailed connection traces and query execution
- Environment variable validation and format checking
- Network connectivity analysis with latency measurements
- Provider-specific diagnostic tools and dashboard integration
- Error message analysis with troubleshooting recommendations
- Manual connection testing with raw database client operations

Debug mode leverages the database abstraction layer's error handling and provider detection logic, providing deep insights into configuration issues, connection problems, and performance bottlenecks across both Turso and Supabase implementations.
